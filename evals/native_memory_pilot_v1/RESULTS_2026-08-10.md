## Boundary diagnosis

The pilot exposed four concrete integration failures:

1. Repository-scoped verified procedures are not reliably usable from a moved checkout when the
   repository has no work-project link. Claude followed the soft adapter and stopped at this safe
   boundary, even though the procedure had been independently verified and stored against the
   stable remote.
2. The soft skill trigger is nondeterministic. One Codex Engram lane used Engram extensively; the
   combined Codex lane ignored the configured server and inspected only native memory.
3. Procedure prerequisites are safe but not ergonomic. Engram correctly rejected missing and
   incorrect `tool.version`, but the host did not reliably translate the diagnostic into an
   authoritative local check of `toolchain.toml` and a second exact match.
4. The structured result contract asks the model to restate identity, evidence, and action labels
   that the trace already proves more reliably. Claude native completed the real command but lost
   acceptance on self-reported metadata and exact shell-shape correlation.

## Recommended next slice

Freeze a boundary-repair pilot for this same case before adding safety cases:

1. Register or derive repository/project/component links during teaching, and make stable
   repository scope sufficient for repository-scoped `procedure_match` without inventing a
   project.
2. Move the Engram cue from a soft optional skill toward a deterministic, bounded harness action
   for fresh-session procedure tasks on both hosts.
3. Return prerequisite keys with explicit guidance to resolve them from authoritative local
   sources, then retry `procedure_match` with the observed value. Do not expose the expected value
   before inspection.
4. Derive canonical identity, evidence, command execution, exit code, and marker from trusted tool
   traces. Keep the model output for intent and abstention, and define root-directory changes
   separately from the learned command.

Only after both Engram arms complete this boundary-repaired case on Codex and Claude should the
program advance to the preregistered wrong-scope and stale-prerequisite safety cases.
