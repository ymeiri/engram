   generic preflight bindings or the authority digest domain.
3. **Descriptor-relative state.** Every applicable root, descendant, xattr, ACL, content, entry,
   and absence observation is no-follow and descriptor-relative under a source-closed class. Held
   descriptor identity, parent inventory, object type, ownership, modes, flags, birthtime, stable
   metadata, content, xattrs, ACLs, and absence predicates are closed without path-prefix,
   caller-selected, post-open, or live-reset authority.
4. **Canonical encoding.** Root streams place each object with its immediate xattrs first, then
   parent-only entry rows, then fixed-order absence rows. `xattr-sequence` resets independently for
   each object and is exactly `0..xattr-count-1` in raw xattr-name byte order. Combined framing,
   counters, integer/hex spelling, limits, row/byte counts, re-encoding, and SHA-256 comparisons are

   pending-call activity are expressly non-authoritative; no stronger zero-postcommit-effect claim
