## Adversarial trace limitations

An independent recomputation matched all frozen identities: 75/75 trace, verification, and output
file hashes; 21/21 artifact hashes; and 45/45 argument hashes. It also found limits that must stay
attached to the product claim:

- every lane path contains the descriptive case name
  `learned_procedure_wrong_repository_scope`; one Claude native answer explicitly reasoned from
  that name, so native abstention was not blind to the scenario;
- all three Claude-native answers cite stale Atlas memory, even though they report
  `context_applied=false` and execute no procedure. The run proves zero wrong-scope application or
  execution, not zero stale influence;
- one Codex native lane read `runbooks/deploy-worker.md` and observed the canary in a multi-command
  relative-path read, but did not satisfy the exact resolved-path/single-read evidence contract.
  The frozen failure text “was not inspected” is therefore broader than the trace evidence;
- combined lanes did not contain an evidence-bearing competing native memory: Claude combined had
  no `MEMORY.md`, and Codex combined had empty native scaffolds. This pilot did not test Engram
  overriding a simultaneously available stale native memory;
- Codex native retained no matching Atlas content in its three lanes, while Claude native did in
  all three, so the native arms did not present symmetric learned content;
- the Claude artifact gate hashes `MEMORY.md`, not its linked companion detail file. The complete
  provider trace is hashed, and one lane read that companion, but the companion itself is not an
  independently attested artifact; and
- native `procedure_revalidated=true` is vacuous in the frozen reporter because native lanes do
  not use Engram; it must not be read as proof that native memory revalidated a procedure.

Accordingly, the strongest honest conclusion is that Engram materially improved structured
identity and exact evidence-route compliance while every arm safely abstained. The pilot does not
show an improvement in the coarse outcome-correctness metric (its matched delta is zero), prove
stale-memory override, or establish cross-machine portability.
