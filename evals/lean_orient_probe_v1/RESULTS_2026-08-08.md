## Outcome

The current Engram 0.2.3 worktree passes the frozen provider-free lean-orientation gate. All 35
fresh-store calls passed their semantic checks, every returned item contained a non-empty
`why_relevant` explanation, and no aggregate latency or packet-size target was violated.

The probe covers known and moved-checkout identity, unresolved ambiguous identity, current and
superseded decisions, no applicable durable context, and current-plan lookup for a

## Boundary of the claim

These are in-process MCP measurements on a deterministic local fixture, not host-visible token
counts, provider latency, or coding-task success. Repository remote correctness is cross-checked
through the same isolated repository service. Native-memory incremental value, provider behavior,
end-to-end first-action correctness, and continuity across actual compaction, service restart, or a
new host session remain reserved for the approval-gated host pilots.

This result supports keeping lean orientation bounded and deterministic. It does not justify adding
semantic candidates to automatic context: retrieval probe v3 separately failed the dense-recall and
selective-auto-application gates. The next provider-free retrieval experiment should measure
structured candidate lanes without auto-applying them.
